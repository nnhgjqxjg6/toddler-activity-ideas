# 了解试管流程，提前做好规划

> 更新时间：2026-09-16 (UTC+8)

**了解试管流程**

**-提前做好规划 -**

1.初诊环节：

女方初诊流程：

挂号（带齐既往检查报告单） → 候诊→ 听到叫号就诊 → 医生进行生育力评估 → 完善相关检查 → 制定治疗方案。

男方初诊流程：

挂号（带齐既往检查报告单）→候诊 → 听到叫号就诊 → 精液检查 → 筛查不育原因，拟定初步诊断，确定诊疗计划，完善相关检查  。

2.术前常规检查：

女方检查项目：染色体、血型（本院）、TCT、HPV、乳腺B超、胸片、心电图、宫颈分泌物（衣原体、淋球菌）、白带常规、传染病、血常规、凝血功能、生化、甲功、尿常规；阴道B超（窦卵泡计数）；

首次必查，再次启动周期，必要时复查：AMH、内分泌、TORCH、卵巢肿瘤标记物、同型半胱氨酸。

男方检查项目：染色体、血型（本院）、精液检查、精子形态学、精子DNA碎片率、尿道分泌物（衣原体、淋球菌）、HSVⅡ型抗体（血清）、传染病、血常规、凝血功能、生化。

3.治疗环节：

医生根据个人病情确定方案促排：

促排注意事项：促排药物一旦开始注射，中间就不能随便停止，并且需要及时来院监测B超和激素水平，医生要根据卵泡发育大小和激素的情况调整促排剂量。

4.扳机：

1、请提前20分钟到院注射（由家属陪同）。

2、请您注意休息，避免剧烈运动（预防卵巢扭转）。

3、男女双方如有跌倒史、晕针、晕血史、手术史、外伤史、过敏史及高血压、糖尿病、癫痫等慢性病史或有长期口服药等特殊事项需及时告知医护人员。

4、男士取集精液必须使用手淫法，如有特殊情况：如取精困难、睾丸活检 （穿刺）、赠精、冻存精子等特殊情况请及时与医护人员沟通。

5.取卵/取精环节：

取卵前一日：

1、需在麻醉方式下取卵的患者请务必于晚24点后禁食、禁水，直至取卵返回病房后，经医生评估后方可进食。

2、夫妻双方术前准备：请勿化妆、喷香水、涂指（趾）甲油，需剪平指（趾）甲，请摘除首饰：项链、戒指、耳环、假牙、手镯、隐形眼镜、发卡，所有摘不下来的首饰请入院当天务必告知护士。

3、请沐浴并更换干净内衣裤。

取卵当日：

1、请男女双方于当日上午（具体时间在您询问打针时间时由护士告知）到急救楼25楼生殖医学护士站报到。

取精须知：

1、如您有高血压、糖尿病等慢性疾病，请您遵医嘱规律用药，同时携带相关用药来院，取精日会为您测量血压。

2、请男士于早餐后携带身份证、结婚证原件到院。

3、取精前一日晚沐浴：注意清洗外阴、阴茎、包皮内污垢并更换内衣：取精当日晨请在家用清水清洗外阴并更换内衣。

4、注意：取精日请勿喷香水，请避免阴毛、衣服纤维等落入精液杯内，如发现，请务必告知工作人员。

5、如有取精困难者，如医生已开药，请务必告知取精室工作人员。

6.移植环节：

注意事项：严格按医嘱用药。切勿自行减量或停用。

7.验孕环节：

移植后的第14天来院查血化验。
