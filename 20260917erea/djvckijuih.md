# 妊娠期高血压居家自我监测

> 更新时间：2026-09-17 (UTC+8)

妊娠期高血压疾病是指妊娠与高血压并存的一组疾病，属于女性高血压的特殊类型，我国患病率为**5.22~5.57％**，包括**妊娠期高血压**、子痫前期、子痫、妊娠合并慢性高血压和慢性高血压并发子痫前期。

**妊娠期高血压的危害**

**对胎儿：**生长受限，严重的时候还会导致胎儿缺氧，也会导致胎儿急性缺血、缺氧、严重的时候还会导致胎儿死亡。

**对孕妇：**头痛、头晕、恶心、呕吐和抽搐的症状，严重者昏迷及心脏衰竭，有可能还会出现暂时性失明。

**家庭自测血压方法：**

**1.孕妇准备：**

①体位舒适，情绪稳定；

②测量前30min 内应避免剧烈运动、进食、喝含咖啡的饮料、吸烟、服用影响血压的药，且保持精神放松、排空膀胱状态, 至少安静休息5min。

**2.环境准备：**室温适宜、光线充足、环境安静。

**3.对需持续观察血压者，应做到“四定”：**定时间、定部位、定体位、定血压计，有助于测定的准确性和对照的可比性。

**自我管理：**

**注意休息：**妊娠期高血压孕妇应保障充足的休息和睡眠，避免过度疲劳。

**合理安排时间：**保证每天有足够的睡眠时间，保持规律的作息习惯，可以午休15～30分钟，但不要过度睡眠，避免影响晚上的睡眠质量。

**创造舒适环境：**确保睡眠环境安静、整洁、温暖，可以使用舒适的床垫和枕头来保证良好的睡眠姿势和体位。左侧卧可解除子宫对静脉的压迫。

**放松身心：**可以尝试做一些放松身心的活动，如听音乐、看书、深呼吸等。避免过度使用电子设备，以免影响睡眠质量。

**随时休息：**在感到疲劳或者不舒服时，随时停下来休息一会，可以尝试坐下或者躺下放松，缓解疲劳感。

**分解家务：**尽量减少或避免一些繁重的家务，如搬运重物、拖地等，可以请亲友帮忙分担。

**规律运动：**根据医生建议，选择适合自己的运动方式，如散步、瑜伽、孕妇体操等。运动不仅能提高体力和免疫力，而且可以提高睡眠质量。

⭐如有头痛、头晕、眼花、胸闷等不适，要及时就医。

⭐降压药服用：定时定量，不可随意增减、停止服药

**预防跌倒：**

①当您在行走中出现头晕、双眼发黑、下肢无力、步态不稳和不能移动时，请立刻扶物靠墙站立或原地坐(蹲)下，呼叫家人/旁人帮助，以防跌倒。

②当您感到头晕、不适或服用镇静安眠、血管活性药物等请卧床休息，如需下床时请呼叫家人帮助。

③改变体位应遵守“三部曲”，即:平躺30秒，坐起30秒，站立30秒再行走，尤其在入厕、洗漱及活动时。

 

**妊娠期高血压的孕妇还要特别关注宝宝的胎动，居家数胎动要这样：**

①取舒适卧位，每日早、中、晚餐30分钟~1小时后各测一次胎动数;

②每次数胎动各数1个小时(5分钟内连续胎动计1次)，每小时正常胎动不应少于3-5次;

③3个小时的胎动数相加乘4为12小时胎动数，若 12小时的胎动数<10 次或次日胎动次数下降 50%提示胎儿有缺氧可能，应立即就医。

数胎动时，孕妈妈要选择安静环境、舒适体位，半卧位、坐位或左侧卧位都可以，尽量不要平躺，把双手自然地放在腹壁上。

最好饭后1小时数胎动，数胎动前尽量排空膀胱 。
